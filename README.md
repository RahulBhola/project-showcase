# Selected Projects

A concise showcase of selected live projects. Both projects are presented here for portfolio purposes; their source code remains in private repositories.

## WealthFlow

Personal finance management with travel expense splitting and investment tracking.

- **Live app:** [wealthflowmanage.vercel.app](https://wealthflowmanage.vercel.app/)
- **Technology:** React 19, TypeScript, Vite, and ASP.NET Core Web API.
- **Source:** Private — [WealthFlow repository](https://github.com/RahulBhola/WealthFlow)

## Shakti Udyog

Digital platform for an iron foundry, with a public marketing site, customer self-service portal, manufacturing Kanban board, and administration ERP.

- **Live app:** [shakti-udyog.vercel.app](https://shakti-udyog.vercel.app/)
- **Technology:** React 19, TypeScript, and ASP.NET Core Web API.
- **Source:** Private — [Shakti-Udyog repository](https://github.com/RahulBhola/Shakti-Udyog)
